FRESH MART APK BUILD FILES

இந்த project-ஐ GitHub-ல் upload செய்தால் GitHub Actions மூலம் install செய்யக்கூடிய debug APK உருவாகும்.

1. GitHub-ல் புதிய repository உருவாக்கவும்: fresh-mart-android
2. இந்த ZIP-ஐ extract செய்து உள்ளே இருக்கும் எல்லா files/folders-ஐ repository-யில் upload செய்யவும்.
3. GitHub repository-ல் Actions tab திறக்கவும்.
4. “Build Fresh Mart APK” workflow தேர்வு செய்து Run workflow அழுத்தவும்.
5. Build முடிந்ததும் workflow run-ல் கீழே Artifacts பகுதியில் Fresh-Mart-APK download செய்யவும்.
6. ZIP-ஐ extract செய்து app-debug.apk-ஐ Android phone-ல் திறந்து install செய்யவும்.

கவனம்: இது debug APK; தனிப்பட்ட Play Store release/signing செய்யப்படவில்லை. App தற்போது live Fresh Mart website-ஐ WebView-ல் திறக்கும். Internet தேவை. Website login / Firebase configuration சரியாக இருக்க வேண்டும்.
